# Micro Task: Empty State Illustration

## Business Problem

When a project has no tasks, users see a plain "No tasks found" text message. This doesn't guide users on what to do next or encourage them to start adding tasks. New users may think something is broken.

## Impact

- New users feel lost when seeing an empty project
- Plain text message feels cold and unhelpful
- No clear call-to-action to guide next steps
- First impressions of the application suffer

## Success Criteria (Observable Outcomes)

- [ ] Empty state displays a friendly visual element (icon or illustration)
- [ ] Helpful message explains the empty state clearly
- [ ] "Create your first task" button or link is prominently displayed
- [ ] Empty state looks intentional, not like an error
- [ ] Clicking the CTA opens the task creation form

## Real-World Context

Empty states are often overlooked but are critical for user onboarding. This task shows how thoughtful UX design guides users and improves engagement.
