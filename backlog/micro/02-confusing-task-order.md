# Micro Task: Confusing Task Order

## Business Problem
Users frequently complain that they can't find their recently created tasks because "tasks appear in random order." The product manager reports that users are creating duplicate tasks because they can't see their most recent work.

## Impact
- Users waste time searching for their own tasks
- Duplicate work reduces productivity
- Poor user experience damages product reputation
- Users lose confidence in the system's reliability

## Success Criteria (Observable Outcomes)
- [ ] Users can immediately find their most recently created tasks
- [ ] Task ordering follows a predictable, logical pattern
- [ ] Order remains consistent across page refreshes and user sessions
- [ ] Sorting behavior matches user mental models for task management

## Real-World Context
This reflects the common UX problem where technical implementation doesn't match user expectations. Your AI agents must understand both the technical data flow and user psychology to find the right solution.
