# Micro Task: Task Sorting Controls

## Business Problem

Users report that tasks appear in an unpredictable order that doesn't match how they work. They want to see their most recent tasks first, or sort by priority to focus on urgent work, but currently have no way to control task ordering.

## Impact

- Users waste time scanning unordered lists to find relevant tasks
- High-priority work gets lost in unsorted lists
- Recently created tasks are hard to find without scrolling
- Users lose confidence in the system's usefulness for daily task management

## Success Criteria (Observable Outcomes)

- [ ] A sort dropdown appears in the task list header
- [ ] Users can sort tasks by creation date (newest/oldest first)
- [ ] Users can sort tasks by priority (high to low, low to high)
- [ ] Users can sort tasks by status (open first, done last)
- [ ] Selected sort option persists during the session
- [ ] Sort happens client-side without page reload

## Real-World Context

Sorting controls are fundamental to any list-based interface. This task demonstrates how a small UI addition significantly improves usability without requiring backend changes.
