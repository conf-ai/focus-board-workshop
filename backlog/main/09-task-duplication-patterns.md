# Main Task: Task Duplication and Patterns

## Business Problem
Teams waste significant time recreating similar tasks manually instead of duplicating existing patterns. Common task structures, recurring activities, and standard procedures require complete recreation each time, leading to inconsistency and reduced productivity.

## Impact
- Daily productivity loss from manually recreating similar task structures
- Inconsistent task setup leads to missed details and quality variations
- Common patterns are not preserved, requiring repeated problem-solving
- Project efficiency decreases when similar work cannot be easily replicated
- Knowledge about effective task structures is lost instead of being reused

## Success Criteria (Observable Outcomes)
- [ ] Users can duplicate existing tasks within the same project
- [ ] Duplication preserves task structure while clearing project-specific details
- [ ] Smart field copying distinguishes between reusable and unique information
- [ ] Duplicated tasks maintain consistency while allowing necessary customization
- [ ] Duplication workflow integrates smoothly with existing task creation
- [ ] Common task patterns become easily replicable across project work

## Real-World Context
Task duplication requires understanding data cloning patterns, selective field preservation, user productivity workflows, and pattern reuse within project management systems.
