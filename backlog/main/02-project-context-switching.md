# Main Task: Expensive Project Context Switching

## Business Problem
Users work across multiple projects but lose significant time when switching between them. They must manually remember and navigate to different project contexts, losing focus and productivity. Analytics show users spend 15+ minutes per day just navigating between project contexts.

## Impact
- Daily productivity loss from context switching overhead
- Mental fatigue from constantly reorienting to different projects
- Mistakes occur when users accidentally work in wrong project context
- User frustration with inefficient navigation patterns
- Competitive disadvantage against tools with better context management

## Success Criteria (Observable Outcomes)
- [ ] Users can switch between projects with single click/action
- [ ] Current project context is always clearly visible
- [ ] Recently accessed projects are immediately available
- [ ] Project switching preserves user's place within each project
- [ ] Context switching works seamlessly across all application areas
- [ ] URL structure reflects current project for bookmarking/sharing

## Real-World Context
Context switching is a major productivity killer in modern applications. This task requires understanding state management, routing, user experience design, and data persistence patterns.
